# Code of conduct

cvfree is a small open-source project. People here want to build a good resume tool and help each other use it.

## Expected

- Be respectful and assume good intent. Disagree with ideas, not with people.
- Give feedback that is specific and useful. Receive it the same way.
- Keep personal data out of issues, PRs and discussions. Use made-up names and sample resumes when you report a problem.
- Help newcomers find their way.

## Not accepted

- Harassment, insults, discrimination or personal attacks, in any channel linked to the project.
- Publishing someone's private information.
- Sustained disruption of discussions or reviews.

## Enforcement

Maintainers may edit, remove or lock content that breaks these rules, and may block people who keep breaking them. Report a problem to the maintainers through a private security advisory on GitHub (Security → Report a vulnerability) if it should not be public, or in an issue otherwise. Reports are handled discreetly.

This document applies to the repository, its issues, pull requests, discussions and releases.
